# Miro Board Exports

Nathan's Miro board is where we brainstorm. Claude Code can't see the live board, so we bring the board to the repo as images:

1. Export from Miro: **screenshots (PNG) or a PDF of the board** — either works. Wire diagrams too.
2. Name the file with the date and topic, e.g. `2026-07-28-tracker-ideas.png`.
3. Drop it in this folder, commit, and push (or just drag the image straight into a Claude Code chat).
4. In a session, say something like *"read the latest Miro export and update the brainstorm doc"* — Claude reads the image and pulls the ideas into `docs/brainstorms/`.

The exports are dated snapshots of our thinking; the distilled decisions live in `docs/brainstorms/`.
